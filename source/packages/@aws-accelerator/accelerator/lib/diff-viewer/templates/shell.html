How to use LZA CDK Diff Viewer

  • Click CloudFormation Diff Summary at the top of the sidebar for an impact report showing high-risk resource changes, affected accounts/regions, and resource type breakdown.
  • Stacks are grouped into sections. Click a section header to expand/collapse.
  • Click a stack name to view its diff.
  • Use the Filter button to show: Unreviewed, Changed, Unchanged, Reviewed, or All.
  • Search by stack name or section.
  • Check the box to mark a stack as reviewed (strikethrough).
  • Unchanged stacks are auto-marked as reviewed. Stacks with only Lambda S3Key changes (asset hash rotation) are treated as unchanged.
  • Diff content is color-coded: red for removals [-], blue for additions [+], yellow for modifications [~].
  • IAM Statement Changes tables highlight entire removal/addition blocks, including continuation rows.
  • In the impact report, use the search box and filter dropdown to find specific stacks. Results are paginated (25 per page).
  • High-risk resource types (VPCs, Transit Gateways, Security Groups, NAT Gateways, etc.) are flagged in the summary with modify/delete counts.
  • Drag the sidebar edge to resize. Toggle theme with ☀️/🌙.
